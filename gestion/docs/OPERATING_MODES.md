# OPERATING_MODES.md

## Planning Mode

Meses/semanas antes:

- edición amplia;
- nuevos proveedores/tareas;
- simulaciones;
- seating iterativo;
- layout iterativo.

## Freeze Mode

Última semana:

- cambios estructurales limitados;
- foco en datos y readiness;
- deploys más restringidos.

## Wedding Day Mode

- operación en tiempo real;
- acceso rápido a invitados/mesas/cronograma;
- mutaciones pequeñas;
- offline fallback;
- cero experimentación.

## Archive Mode

Después:

- lectura/archivo;
- exportaciones;
- revocar accesos temporales;
- política de retención;
- aprendizajes no sensibles.

Estos modos pueden comenzar como política operativa antes de convertirse en feature flags de producto.
