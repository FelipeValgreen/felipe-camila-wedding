# GO_LIVE_CRITERIA.md

## Aplicación

- CI verde;
- Preview validado;
- no P0 abiertos;
- rollback disponible.

## Datos

- migraciones aplicadas/verificadas;
- RLS/grants;
- integridad P0;
- backup.

## Operación

- módulos críticos usables;
- sync sano;
- health/observability;
- responsables.

## Evento

Go-live técnico no equivale a `WEDDING_DAY_READY`; este último además requiere seating, cronograma, proveedores, offline pack y decisiones humanas finales.
