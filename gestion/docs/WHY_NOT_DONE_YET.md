# WHY_NOT_DONE_YET.md

El sistema no se declara terminado sólo por tener documentación o módulos visibles. Las brechas que bloquean un cierre técnico verificable son:

- suite formal de tests de gestión;
- `check:ci` real;
- staging full-stack para mutaciones E2E;
- alineación de docs con código/migraciones;
- verificación vigente de seguridad/credenciales;
- simulacro de restore;
- decisiones operativas finales de seating/layout/cronograma/música.

Este archivo debe eliminarse o archivarse cuando `DEFINITION_OF_DONE.md` esté cumplido.
