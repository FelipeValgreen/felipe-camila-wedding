# Documentación del Centro de Gestión

La documentación canónica del subproyecto vive aquí y en los Markdown de la raíz de `gestion/`.

Empieza por [`DOCUMENTATION_INDEX.md`](./DOCUMENTATION_INDEX.md).

## Regla

No usar documentos históricos de `/docs` raíz como estado actual de `gestion/**` sin verificación contra código/migraciones vigentes.

## Categorías

- arquitectura/datos/dominio;
- seguridad/RBAC;
- entornos/CI/tests;
- observabilidad/recuperación/release;
- operación del evento;
- `ADR/` para decisiones durables;
- `specs/` para dominios complejos;
- `audits/` para auditorías fechadas;
- `handoffs/` para trabajo incompleto.
