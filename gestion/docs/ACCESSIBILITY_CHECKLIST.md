# ACCESSIBILITY_CHECKLIST.md

Objetivo: WCAG 2.2 AA razonablemente aplicable para los journeys críticos.

## Global

- [ ] landmarks y headings coherentes;
- [ ] navegación por teclado;
- [ ] focus visible;
- [ ] contraste suficiente;
- [ ] textos no dependen sólo de color;
- [ ] zoom 200% utilizable;
- [ ] reduced motion respetado donde aplique.

## Formularios

- [ ] labels asociados;
- [ ] instrucciones antes del error;
- [ ] errores vinculados al campo;
- [ ] estado disabled/readonly claro;
- [ ] confirmaciones no dependen sólo de toast efímero.

## Mesas / salón

- [ ] alternativa a drag & drop;
- [ ] selección por teclado cuando sea razonable;
- [ ] controles de mover/asignar/quitar accesibles;
- [ ] no depender de hover;
- [ ] targets táctiles adecuados.

## Tablas/listados

- [ ] encabezados;
- [ ] búsqueda/filtros accesibles;
- [ ] responsive no obliga a scroll horizontal para tareas P0;
- [ ] estados vacíos explicativos.

## Modales/drawers

- [ ] focus trap;
- [ ] Escape;
- [ ] devolver focus;
- [ ] título accesible;
- [ ] acción destructiva diferenciada.

## Copiloto

- [ ] acción propuesta legible antes de confirmar;
- [ ] loading anunciado;
- [ ] errores no sólo visuales;
- [ ] streaming no impide lectura con lector de pantalla.
