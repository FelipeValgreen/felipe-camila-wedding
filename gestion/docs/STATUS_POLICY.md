# STATUS_POLICY.md

`STATUS_AND_ROADMAP.md` describe capacidades, no conteos live. Los estados deben basarse en evidencia:

- ✅ código + contrato verificable;
- 🧪 implementado pero no completamente probado;
- 🟡 limitación conocida;
- 🔴 bloqueante;
- ⚪ futuro.

No usar ✅ sólo porque existe una página o un Markdown.
