# MOBILE_CRITICAL_FLOWS.md

Durante el evento, móvil es una experiencia de primera clase.

## P0

- buscar invitado;
- ver asistencia;
- ver mesa;
- cambiar mesa con validación;
- ver restricciones si el rol está autorizado;
- abrir cronograma actual/próximo;
- ver proveedor/contacto day-of;
- registrar incidencia;
- ver health básico.

## Requisitos

- sin tablas horizontales obligatorias;
- botones táctiles;
- drawers/modals manejables con teclado/touch;
- búsqueda rápida;
- no depender de hover;
- estados offline/degradados comprensibles.
