# OPERATIONS_EXPORTS.md

## Objetivo

Definir los entregables offline mínimos que el Centro de Gestión debe poder producir antes del evento.

## Exportaciones P0

### Invitados + seating

Campos mínimos:

- nombre;
- asistencia final;
- mesa;
- categoría/grupo operativo útil;
- restricción sólo en versión autorizada para catering;
- estado de incidencia cuando sea necesario.

### Plano

- versión/timestamp;
- mesas/nombres/números;
- accesos;
- pista/escenario/barra y elementos críticos.

### Cronograma

- hora;
- actividad;
- responsable;
- proveedor;
- ubicación;
- cue;
- contingencia breve.

### Proveedores day-of

- empresa/categoría;
- contacto autorizado;
- llegada;
- montaje/desmontaje;
- responsabilidad;
- notas críticas.

### Música/AV

- momento;
- track/versión;
- cue;
- prioridad;
- responsable.

## Privacidad

Generar versiones por audiencia. No entregar el mismo archivo con restricciones, finanzas y teléfonos completos a todos los proveedores.

## Formatos

- PDF legible;
- CSV/XLSX para operación tabular cuando corresponda;
- timestamp visible;
- identificación de versión.

## Validación

T-24 abrir cada exportación en un dispositivo distinto y confirmar que no depende de recursos remotos para ser legible.
