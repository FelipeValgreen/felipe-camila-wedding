# STOP_CONDITION.md

La fase de cierre termina cuando:

- documentación canónica coherente;
- code gap audit completo;
- scripts/tests/CI mínimos implementados;
- PR abierto y Preview verificable;
- bloqueos externos/humanos aislados con evidencia;
- no queda trabajo ejecutable por el agente dentro del alcance actual sin requerir credenciales/decisiones humanas.
